Hyundai Elantra N Web Driving Game
Upload/extract the ZIP contents to an HTTPS static web host (e.g. GitHub Pages), then open index.html.
Uses Three.js modules loaded from jsDelivr CDN, so internet access is required.
Controls: on-screen buttons or WASD/arrow keys. Brake also reverses.
The model's orientation and initial spawn may need tuning for the specific map layout.
Note: This is a web game package, not a native Lens Studio .lsproject. Lens Studio cannot import this ZIP as a native Lens Studio project; for Lens Studio use its supported web embedding/workflow if available, or import GLB models and recreate gameplay natively.
